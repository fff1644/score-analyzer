# 成绩统计分析器

一个简单的C语言程序，输入10个学生的成绩，输出：
- 最高分、最低分、平均分
- 从高到低排序后的成绩
- 各分数段人数分布（90以上、80-89、70-79、60-69、60以下）

## 如何运行
用任意C编译器编译运行即可（如Dev-C++、VS Code + MinGW）。

## 示例
输入：85 92 78 64 95 88 76 81 59 93  
输出：  
最高分：95  
最低分：59  
平均分：81.10  
排序：95 93 92 88 85 81 78 76 64 59  
90以上：2人  
80-89：4人
